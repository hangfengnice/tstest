# 每日自评模板

复制到当天 NOTES.md 的自评节，由学习者本人填写；已有复盘保留，只补缺失信息。
每天用三句话完成，复杂问题再展开。

1. 今天最卡的是：____；我选择这个类型设计的原因是：____。
2. 我获得了 ____ 次提示（不记得写“未记录”），帮助来自 ____，提示内容是 ____。
3. 明天我准备换成 ____ 场景独立重写 ____，重点验证 ____。

提示包括 AI、他人指导和参考答案；主动查文档也记录，但不直接等同于没有掌握。

## 验收记录

- 当天代码：`pnpm check:day XX`，结果 ____。
- 解释：为什么选这个设计？一个错误用法为什么应当被拒绝？____。
- 隔天重做：日期 ____；不看原实现和答案；实际结果 ____；仍需要的提示 ____。

隔天重做时先保存原实现，用变化后的场景重写核心部分，并调整对应验收用例。
确认类型检查与运行时测试都通过后，再恢复原练习；不要用未保存的原代码做覆盖实验。
空白记录表示尚未验证，不自动推断为掌握或不掌握。

## 从 Day 1 重学时的追加格式

保留原 NOTES，在末尾追加，不替换旧结论：

```markdown
## 重学 YYYY-MM-DD

- 本次完成范围：
- 当天验收命令与实际结果：
- 能独立解释的概念及反例：
- 获得的提示、来源、次数：
- 隔天迁移场景与实际结果（待重做后填写）：
- 自评（本人填写）：
```

将三项结果同步到 [本轮重学记录](./RELEARNING-PROGRESS.md)。运行参考答案验证、整理文档或提交文件，不计为本人完成练习。
